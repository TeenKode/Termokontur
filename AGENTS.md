# Правила изменений Термоконтура

## Версионирование

- При **каждом** изменении проекта повышайте версию приложения в `termokontur/__init__.py` (`__version__`). Это относится и к небольшим исправлениям, текстам и интерфейсу MAX-бота.
- Используйте SemVer: `PATCH` для совместимых исправлений и улучшений, `MINOR` для новых обратно совместимых возможностей, `MAJOR` для несовместимых изменений.
- В одном PR достаточно одного повышения версии, даже если он меняет несколько файлов. Если целевая ветка уже получила тот же номер, пересчитайте следующую версию перед слиянием.
- Панель и прошивки одного релиза используют `__version__` из `termokontur/__init__.py`. Сборки прошивок считывают эту версию автоматически.

## Проверка

- Проверяйте автоматические тесты и обновляйте тесты, чувствительные к изменённым сообщениям или кнопкам.
- Не меняйте callback payload при косметических правках подписей MAX-бота: это может нарушить уже отправленные кнопки.
