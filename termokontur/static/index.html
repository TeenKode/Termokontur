Как подключить учителя? Для одного кабинета используйте «Код MAX» (30 минут). Для нескольких — «Коды подключения MAX»: выберите помещения, срок действия и выгрузите CSV для Excel. Каждый код одноразовый, а новый выпуск аннулирует прежние неиспользованные коды выбранных кабинетов.
