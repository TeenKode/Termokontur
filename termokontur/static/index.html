      Загрузите сертификат с полной цепочкой (fullchain.pem).

      Можно заменить один файл из сохранённой пары. Максимум 256 КБ на файл. По HTTP загружайте ключ только через доверенную сеть или SSH-туннель.

      Выберите один или два файла.

      После перезапуска откройте сайт: . Для внутреннего УЦ понадобится доверие к нему на компьютерах.

      HTTP: порт 8092. HTTPS: порт 443. Перед переключением убедитесь, что порт 443 свободен; при внешнем прокси проверьте его настройки.

      Сертификаты для датчиков

      Для собственного центра сертификации загрузите его корневой сертификат и, если есть, промежуточные сертификаты. Закрытый ключ не нужен. Настройка не изменяет HTTPS панели и не требует перезапуска.
