# Схемы соединений автономного датчика

Редактируемые файлы KiCad 9; исходная версия инструмента — 9.0.2.
Откройте соответствующий `.kicad_pro` и его `.kicad_sch` в KiCad.
Кэш символов сохранён внутри схем, собственные представления модулей —
в `Termokontur.kicad_sym`, таблица библиотек — `sym-lib-table`.
Для стандартных символов используется установленная библиотека KiCad 9.

| Лист | Назначение |
|---|---|
| `01-power` | BL-5C, защищённый TP4056, SW1, SuperMini, дополнительная развязка |
| `02-charge-adc` | Q1/R1–R3: детектор USB; R4/R5/C1: измерение батареи |
| `03-i2c` | SHT3x/SHT4x/AHT20, GPIO6/7, подтяжки |
| `04-bme280` | BME280, GPIO6/7, CSB и SDO |
| `05-dht` | Совместимый с 3,3 В модуль DHT11/DHT22, GPIO5 |
| `06-ds18b20` | Один DS18B20 с отдельным VDD, GPIO5 |

Это шесть самостоятельных представлений одной сборки. A1 повторяется для
читаемости; физически ESP32-C3 одна. Листы 3–6 — альтернативы. Не суммируйте
их BOM как шесть установленных датчиков. Числа выводов DS18B20/2N3904 относятся
к выбранным библиотечным корпусам; расположение модульных контактов показано
по маркировке, а не как монтажная фотография платы.

## Воспроизведение

Из корня репозитория, с установленными KiCad 9 CLI и стандартными библиотеками:

```sh
.venv/bin/python -m pip install sexpdata pypdf scour
.venv/bin/python scripts/draw-sensor-schematics.py
```

При нестандартной установке задайте `KICAD9_SYMBOL_DIR`. Генератор создаёт
схемы, экспортирует SVG и общий шестистраничный PDF, запускает ERC и проверяет
реальные KiCad netlist по ожидаемым соединениям. Любое нарушение ERC или
несовпадение заданной цепи завершает сборку ошибкой. Профиль CLI для проверки
создаётся отдельно в `/tmp/termokontur-kicad-*`.

- `*.net` — экспортированные KiCad XML-списки соединений.
- `*.erc.json` — полные отчёты KiCad ERC, без исключённых нарушений.
- `validation.json` — отчёты и ожидаемые наборы выводов каждой цепи.
- [SVG, общий PDF и пояснения](../../docs/sensors/SCHEMATICS.md).

Проверка ERC относится к соединениям и используемым символам. Модульные
представления не моделируют внутренности SuperMini/TP4056; поведение защиты,
стабилизатора, АЦП, ток сна и обратное питание проверяются на стенде.
Это не разводка PCB, SPICE-модель и не результат аппаратных испытаний.
Ромбы PWR_FLAG — служебные указания источников питания для ERC, не детали для покупки.

Стандартные обозначения Device, Switch, Transistor_BJT, Sensor_Temperature и
power взяты из библиотек [KiCad](https://gitlab.com/kicad/libraries/kicad-symbols).
Лицензия — [CC-BY-SA 4.0 с исключением библиотеки](https://www.kicad.org/libraries/license/).
Собственные блоки показывают подписанные выводы модулей, без предположений
о расположении контактов на конкретной плате.
