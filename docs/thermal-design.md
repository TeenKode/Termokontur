# Thermal Graphite / Graphite Light — v0.2

Локальные шрифты Manrope и JetBrains Mono (переменные TrueType, нормальное начертание), оригинальные файлы Google Fonts, SIL OFL 1.1: `termokontur/static/fonts/`. Нет запросов к внешним CDN. WOFF2 можно подготовить позже без изменения визуальной системы. Существующая PNG-иконка Apple Touch оставлена для совместимости; панель и favicon используют новый SVG.

Токены и адаптивные компоненты находятся в `termokontur/static/thermal-design.css`; используются действующие API и DOM-идентификаторы. Состояния температуры определяются нормами помещения, а состояние датчика — сервером с учётом расписания связи. Не подменять эти данные демонстрационными.

Браузерный тест проверяет обе темы, 7 разделов, 5 размеров экрана, локальную загрузку шрифтов, таблицу датчиков, инспектор и переход из оперативного блока. Физическая плата проверяется отдельно.
