# Прошивка через браузер

Рекомендуемый способ — [USB-мастер в панели Термоконтура](USB-ONBOARDING.md). Он записывает прошивку, сохраняет настройки и автоматически выдаёт доступ плате.

## Какой файл выбрать

| Файл | Назначение |
|---|---|
| ZIP-комплект | Ручная загрузка в **Датчики → Прошивки → Загрузить комплект ZIP для ESP32-C3** |
| `factory.bin` | Первая ручная запись на ESP32-C3: адрес 0x0, DIO, 80 MHz, 4 MB |
| `firmware.bin` | Обновление работающего датчика через карточку |

Полная запись удаляет настройки. USB-мастер также очищает весь журнал. Ручная запись `factory.bin` может оставить часть старого журнала за пределами образа: не используйте её как сброс действующей платы.

## Внешний инструмент Espressif

1. Скачайте полный образ для USB в **Датчики → Прошивки**. Если используете ZIP из GitHub Actions, распакуйте его и проверьте `SHA256SUMS`.
2. Разомкните SW1, отключите USB зарядки TP4056 и подключите USB SuperMini кабелем с данными.
3. Откройте [Espressif ESP Tool](https://espressif.github.io/esptool-js/) в Chrome или Edge на компьютере.
4. Нажмите **Connect** и выберите порт ESP32-C3. Если нужно, используйте BOOT/RESET.
5. Добавьте `factory.bin` по адресу `0x0`: DIO, 80 MHz, 4 MB, 115200 baud. Не включайте **Erase all**.
6. Нажмите **Program** и дождитесь проверки записи.
7. Освободите порт и продолжите через **Настроить без прошивки** в панели либо [настройте с телефона](SETUP.md).

Если браузер не видит порт, используйте `flash-sensor.py` из комплекта. Команды для Windows, Linux и macOS есть в [SETUP.md](SETUP.md).

## Для разработчиков

В панели используется локальный esptool-js 0.5.7 без CDN. Мастер проверяет файл, чип, память и регистрацию платы перед стиранием. Затем записывает образ и передаёт настройки через USB.

Сборка комплекта: `python scripts/package-sensor.py`. Нужны `platformio==6.1.18` и `esptool==4.5.1`.

USB-сценарий проверен с имитацией платы. Реальная запись требует [стендовой проверки](BENCH.md).
