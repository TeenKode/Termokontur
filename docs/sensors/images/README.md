# Снимки руководства

Снимки созданы `scripts/capture-sensor-guide.py` на изолированной временной
базе данных. Рабочие пароли, коды и данные пользователей не используются.
Код регистрации дополнительно заменён демонстрационной подписью до снимка.

- `01-sensors.jpg` — настоящий раздел панели без зарегистрированных плат.
- `02-create.jpg` — форма создания устройства с выбранным помещением.
- `03-code.jpg` — окно ID и кода; код скрыт.
- `04-phone-setup.jpg` — точная HTML-страница из исходника прошивки,
  отрисованная Chromium с шириной 440 px. Добавлена пометка о демонстрации;
  физическое Wi-Fi-подключение и отправка реквизитов не выполнялись.
- `05-readings.jpg` — настоящая карточка панели, показания имитированы через API.
- `06-config.jpg` — настоящая форма настройки с интервалами стендового прогона.
- `07-ota.jpg` — настоящий интерфейс с загруженным образом и назначением
  версии для имитированного устройства; физический OTA не выполнялся.
- `08-rekey.jpg` — настоящая форма с кнопкой перевыпуска ключа.
- `09-setup-password.jpg` — раздел собственного пароля точки настройки из
  HTML прошивки; данные демонстрационные, на плату они не отправлялись.

Это снимки интерфейса, а не подтверждение аппаратных испытаний. USB-флешер,
выбор физического COM-порта и работа кнопок на реальной ESP здесь не сняты.

Повторное получение из корня репозитория (нужен собранный firmware.bin):

```sh
.venv/bin/python -m pip install playwright
.venv/bin/python -m playwright install chromium
.venv/bin/python scripts/capture-sensor-guide.py
```

Можно указать существующий Chromium через переменную `CHROMIUM_PATH`.
Скрипт поднимает отдельный сервер на свободном локальном порту, выполняет
сценарии, сохраняет изображения и удаляет временную базу при завершении.
Время, случайные ID и номера записей на повторных снимках могут отличаться.
