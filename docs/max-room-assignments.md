# Кабинеты и коды MAX

## Подключить сотрудника

1. Откройте **Помещения → Коды MAX**.
2. Выберите корпус и кабинеты. По умолчанию показаны кабинеты без сотрудников и действующих кодов.
3. Укажите срок действия: от 30 минут до 7 дней. За один раз можно выбрать до 250 кабинетов.
4. Нажмите **Создать коды**.
5. Скопируйте команды `/bind КОД` или скачайте CSV. Передайте каждому сотруднику его команду.

Сохраните коды до закрытия окна: повторно они не показываются. Каждый код одноразовый. Новый код для кабинета отменяет предыдущий неиспользованный код, но сохраняет подключённых сотрудников.

## Отключить сотрудника или код

В таблице **Помещения** нажмите **Отвязать** рядом с сотрудником. Удалится только его связь с выбранным кабинетом; история и остальные связи сохранятся.

В **Коды MAX → Действующие коды** нажмите **Отозвать**, чтобы отменить неиспользованный код. Для повторного подключения создайте новый.

Имя сотрудника появляется после его обращения к боту. Если имени нет, отображается ID MAX.

## Несколько сотрудников в кабинете

У кабинета одно общее показание MAX за местный календарный день. Его может отправить любой подключённый сотрудник.

- **Отправить** — добавить первое показание или исправить сегодняшнее показание MAX, в том числе отправленное коллегой.
- **Показания** — проверить результат за сегодня.

В истории остаются первое значение, автор и исправления. Показания датчика и администратора через MAX не меняются.

Напоминание приходит, если за день нет показаний ни от одного источника. При выходе ручного измерения за норму отправитель получает предупреждение в ответе бота, коллеги — отдельное сообщение. Повторные сообщения ограничены.

## API для разработчиков

Маршруты требуют сеанса администратора:

- `GET /api/rooms` — помещения и поле `max_users`.
- `DELETE /api/rooms/{room_id}/max-bindings/{user_id}` — отключение сотрудника.
- `GET /api/max/pairing-codes` — действующие коды без секретных значений.
- `POST /api/max/pairing-codes` — выпуск кодов для однократного показа.
- `POST /api/max/pairing-codes.csv` — выпуск и экспорт CSV.
- `DELETE /api/rooms/{room_id}/pairing` — отзыв кода.
- `GET /api/readings/{reading_id}/corrections` — история исправлений.

В базе сохраняются только хеши кодов. Повторные события MAX не создают дубликатов измерений и исправлений.
