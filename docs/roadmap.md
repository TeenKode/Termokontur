# План развития

## v0.1 — первый рабочий прототип
- [x] Репозиторий, сервер FastAPI, SQLite, базовые проверки, веб-панель.
- [x] Корпуса, помещения, индивидуальные диапазоны, показания и история.
- [x] Ручной ввод администратора, экспорт CSV.
- [x] MAX: одноразовая привязка и ввод температуры; Long Polling для **тестов**.
- [x] API датчиков для Home Assistant.
- [x] Debian 12/13 native LXC installer с systemd и отдельный Docker Compose.
- [ ] Протестировать на реальном сервере Proxmox, с MAX-ботом и физическим датчиком.

## v0.2 — администрирование из панели
- [x] Настройки организации, MAX, времени измерений, напоминаний и ключей датчиков в SQLite.
- [x] Смена пароля с завершением прежних сессий.
- [x] Массовое добавление кабинетов с диапазонами и предварительным просмотром.
- [x] Проверка и запуск обновления через отдельную root-службу (только native Debian LXC).
- [ ] Испытание native updater на настоящем Proxmox LXC и проверка rollback на сбое.

## v0.2.1 — удобство управления
- [x] Упрощённая политика паролей: минимум 8 символов, без требований к их типам.
- [x] Показ/скрытие и проверка совпадения нового пароля в интерфейсе.
- [x] Поиск кабинетов, восстановление отключённых, копирование шаблона кабинета.
- [x] Экспорт реестра помещений в Excel-совместимый CSV.

## v0.2.2 — массовая выдача кодов MAX
- [x] Выбор кабинетов, фильтр корпуса, массовое выделение.
- [x] Генерация одноразовых кодов, выбор срока действия и экспорт CSV с командой `/bind`.
- [x] Аннулирование старых неиспользованных кодов при перевыпуске, сохранение в БД только хешей.
- [x] Тесты полномочий, повторного использования, сроков, атомарности и CSV.
- [ ] Проверить выдачу кодов и подключение сотрудников на реальном MAX-боте.

## v0.2.3 — надёжность интеграций
- [x] Проверка авторизации входящих HTTPS webhook по секретному заголовку.
- [x] Подключение/отключение webhook через веб-панель.
- [x] Устойчивая очередь ответов MAX и защита от повторного выполнения одного события.
- [x] Повторное использование результата привязки при повторе того же message ID.
- [ ] Пилотное испытание MAX API с реальными пользователями и доменом.
- [x] Ручная диагностика очереди MAX и проверка наличия webhook-подписки в панели.\n- [ ] Автоматические оповещения администратору о недоступности webhook и о постоянно ошибающихся адресатах.

## v0.2.4 — обслуживание и оповещения
- [x] Копирование и восстановление SQLite через настройки, страховочная копия и отзыв сессий.
- [x] Импорт/экспорт резервных копий с проверкой целостности и прав доступа.
- [x] Настраиваемые автоматические копии и ротация старых авто-копий.
- [x] Настраиваемый срок хранения измерений, по умолчанию без удаления.
- [x] Оповещения о температурных отклонениях с ограничением частоты сообщений.
- [x] Автоматическое обновление панели каждые 30 секунд, улучшение мобильных диалогов.
- [ ] Испытание резервного копирования и отката на реальном Debian 13 LXC.
- [ ] Отдельные уведомления для администрации и график рабочих/нерабочих дней.
