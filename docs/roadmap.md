# План развития

## v0.1 — первый рабочий прототип
- [x] Репозиторий, сервер FastAPI, SQLite, базовые проверки, веб-панель.
- [x] Корпуса, помещения, индивидуальные диапазоны, показания и история.
- [x] Ручной ввод администратора, экспорт CSV.
- [x] MAX: одноразовая привязка и ввод температуры; Long Polling для **тестов**.
- [x] API датчиков для Home Assistant.
- [x] Debian 12/13 native LXC installer с systemd и отдельный Docker Compose.
- [ ] Протестировать на реальном сервере Proxmox, с MAX-ботом и физическим датчиком.

## v0.2 — администрирование из панели
- [x] Настройки организации, MAX, времени измерений, напоминаний и ключей датчиков в SQLite.
- [x] Смена пароля с завершением прежних сессий.
- [x] Массовое добавление кабинетов с диапазонами и предварительным просмотром.
- [x] Проверка и запуск обновления через отдельную root-службу (только native Debian LXC).
- [ ] Испытание native updater на настоящем Proxmox LXC и проверка rollback на сбое.

## v0.2.1 — удобство управления
- [x] Упрощённая политика паролей: минимум 8 символов, без требований к их типам.
- [x] Показ/скрытие и проверка совпадения нового пароля в интерфейсе.
- [x] Поиск кабинетов, восстановление отключённых, копирование шаблона кабинета.
- [x] Экспорт реестра помещений в Excel-совместимый CSV.

## Следующие итерации
- [ ] MAX Webhook через HTTPS/Tunnel вместо экспериментального Long Polling.
- [x] Напоминания учителям по будням с настраиваемым временем, часовым поясом и защитой от дублей (по умолчанию выключены).
- [ ] Исключение школьных каникул и праздничных дней из расписания напоминаний.
- [ ] Права: администратор, ответственный по корпусу, сотрудник для ручного ввода.
- [x] Контроль сдачи показаний за текущий местный день в панели и MAX.
- [x] Управление общим расписанием напоминаний из веб-панели.
- [ ] Индивидуальные графики замеров для разных кабинетов.
- [ ] Периоды и фильтры истории, агрегаты и отчёты Excel/PDF.
- [ ] Калибровка датчиков, контроль батареи и связи, сигналы длительных отклонений.
- [ ] Массовый импорт помещений и сотрудников.
- [ ] Конфигурируемый срок хранения, ротация и автоматические резервные копии.
- [ ] Проверка доступности интерфейса, мобильной версии, тесты интеграций.
- [ ] Возможность нескольких организаций/объектов при необходимости.

Указанные диапазоны в карточках кабинетов — настраиваемые пороги, не автоматическое определение санитарных нормативов.
