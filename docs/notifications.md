# Рассылка уведомлений через MAX

Откройте **Настройки → Уведомления**. На странице доступны:

- автоматические напоминания о пропущенных измерениях и температурные предупреждения;
- разовая адресная рассылка всем привязанным сотрудникам, сотрудникам конкретного корпуса, сотрудникам без сегодняшних измерений или вручную выбранным получателям;
- предварительный просмотр количества получателей и их имён;
- обычная или тихая отправка без push-оповещения;
- история рассылок с количеством принятых MAX сообщений и ожидающих повторной доставки.

В каждой рассылке человек учитывается единожды, даже если за ним закреплено несколько кабинетов. В список попадают только сотрудники с привязками к активным помещениям.

Для доставки необходимы действующий токен MAX и работающая служба `termokontur-max`. Сообщения сохраняются в базе SQLite до доставки, отправляются отдельными сообщениями и не перезаписывают меню бота. Повторный запрос с тем же идентификатором не создаёт дублей. Перед отправкой панель показывает подтверждение с текстом и количеством получателей.

**Важно:** «В очереди» не равно «доставлено». Система считает сообщение отправленным только после успешного ответа API MAX, а не после фактического просмотра сотрудником. Неудачные попытки повторяются с увеличивающимся интервалом. Температурные предупреждения отправляются только по показаниям автоматических датчиков Home Assistant. Ручные показания не инициируют повторную отправку того, что сотрудник уже знает: о выходе за норму сообщается сразу в ответе бота. Предупреждения по датчикам не дублируются без нового измерения, даже когда истёк интервал ограничителя.
